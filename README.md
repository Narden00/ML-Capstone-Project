# House Prices - Machine Learning Capstone Project

## Project Overview
This project uses the House Prices dataset to apply three machine learning techniques:
- Regression using Linear Regression.
- Classification using Logistic Regression.
- Clustering using K-Means.

## Dataset
House Prices - Advanced Regression Techniques from Kaggle.

## Project Structure
- `data/`: Dataset files.
- `notebooks/`: Jupyter Notebook containing the project code.
- `results/`: Model results and visualizations.
- `project_report.pdf`: Final project report.

## Models and Results
- Linear Regression: R² = 0.4437
- Logistic Regression: Accuracy = 94.86%
- K-Means: Silhouette Score = 0.1044

## Tools
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Google Colab.
